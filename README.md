# 防汛需求与道路情景覆盖数据分析平台

预案分析员在暴雨情景下比较居民在不同出发时刻，能否沿**可通行道路**到达**既有安置点**，
并区分覆盖面变化究竟来自**道路恢复、人口资料变化还是分析边界改变**。

在冻结的**网格常住人口基线**之上，平台进一步按**网格 × 时段**计算**临时暴露人口区间**：
对移动信号、景区/寄宿学校在场记录与临时转移登记做时间窗对齐、来源覆盖评估与重叠处理，
输出临时增加/减少人数的**下界、上界、采用证据与不可估计范围**，分析员可把区间叠加到基线，
观察暴雨期间旅游客流、寄宿学校在校与临时转移造成的**短时可达需求变化**。

平台只计算**可达人口及证据限制**，不做安置点选址、人员分配或物资调运。

技术栈：**React 18 + TypeScript + Vite + Leaflet（离线 Simple CRS 平面地图）**、
**FastAPI**、**PostgreSQL 18**、**Redis 8（失效通知/任务状态，可选降级）**。

## 3. 数据与口径说明

### 3.1 来源目录（全部带原文、单位、发生/登记时间、修订号与证据截止点）

- 规则网格人口（含修订表与基准日）、路网节点、**有向边修订**、安置点及开放区间、
  封路/分时限速事件（**追加式多修订行** + 修订审计）、区域边界；
- 每个网格保存与路网的**连接位置与互斥分配比例**；多出口网格按互斥子份额切分人口；
- 事件每次修订只追加新行（含 `received_at`），快照按截止点取该事件最新的**可见**修订；
  因此旧截止点分析在新修订录入后仍可精确复现，不会被原地 UPDATE 改写历史。

### 3.2 情景工作区固定四项输入

人口基准日、出发时刻、允许行程时长、道路资料截止点（另可选分析边界）。
四要素 + 路网版本 + 边界共同组成**完整情景签名**，作为缓存唯一键。

### 3.3 时变路网求解规则（`app/engine/traversal.py`）

1. 遍历边时检查**整条通行时段** `[进入, 离开)` 是否与封路区间相交，而非只看出发时刻；
2. 分时限速按覆盖整段的最严格限速计算（定点细化）；
3. 仅 `allow_wait` 节点可等待道路恢复，等待段与等待成本逐段记录；
4. 等待后到达仍超出总时限的标签被剪枝，**不计入覆盖**；
5. 安置点按**实际到达时刻**判断开放；到达时关闭且节点允许等待，可等到下一开放区间起点，
   等待同样计入总时长；
6. 每个标签携带见证路径（节点序列 + 边序列 + 等待段）。

### 3.4 覆盖、去重与未知边界

- 份额人口 = 网格人口 × 互斥比例；同一份额能到多个安置点只计一次（取最早实际到达）；
- 网格级汇总天然去重，同一网格人口绝不重复计数；
- 未知单列且不默认全覆盖或零需求：
  `unknown_no_connector`（无连接）、`unknown_allocation_gap`（比例缺口）、
  `unknown_ratio_over_one`（比例矛盾）、`unknown_connector_missing`（连接节点不在该路网版本）。

### 3.5 混合计算与缓存纪律

- 常规出发窗口**预计算**；临时封路/限速登记后立即参与后续**即时计算**；
- 每项结果标注**证据截止时间**；不同出发时刻/开放条件签名不同，缓存命中也不复用他者覆盖面；
- 封路修订沿 `task_edge_dependencies` 定位受影响任务，并显式筛查**恢复候选**
  （路网含该边但旧路径未经过的任务——重开可能恢复此前不可达区域）；
- 同截止点迟到修订物化为**新路网版本**（新指纹、新 version_id、新签名），
  旧任务物理上无法覆盖新版本缓存行；重建期间的路网更新只会再产生新版本。

### 3.6 对比报告的共同分母

- 仅在两侧共有的网格集合上计算覆盖率与变化；
- 道路/开放窗口效应、人口修订效应、分析边界增删、未知份额变化**分桶展示**；
- 人口或边界口径不一致时给出显式警告，不能把换了分母的覆盖率当作改善；
- 发布记录（`publications`）固化两侧完整输入清单（修订号、截止点、版本指纹、网格人口与边界）。

### 3.7 临时暴露人口区间（网格 × 时段，叠加于冻结基线）

模块以**输入快照**关联、互不共享可变状态：
`人口基线(pop_grids) → 临时信号接入(mobile/venue/transfer 三表) → 覆盖率/重叠校准
(exposure_input_snapshots + exposure_overlap_rules) → 区间计算(exposure_estimates/
exposure_grid_periods) → 情景发布(publications 关联 estimate_id)`。

- **时间窗对齐**：只取与分析窗口相交且 `received_at ≤ 证据截止点` 的来源；窗口仅部分
  相交时禁止按时间比例外推，只给开放上界（下界 0、上界不可估）。
- **校准路径（精度高、依赖代表性）**：仅当运营商**覆盖率稳定且经现场核验**、且存在同口径
  分层校准系数时，才把采样人数 × 系数扩展为在场人数，并给 `点估计 ± 抽样相对误差` 区间；
  覆盖率不稳/未核验/缺系数时退回保守路径。
- **保守路径（更保守、未知更宽）**：已核实签到/点名/登记人数作**下界**，场所**容量**约束
  上界；转移登记为已核实确定值。没有上限约束的来源上界留 `NULL`（不可估计），绝不外推。
- **重叠处理（Fréchet 界）**：只有可证明关系才收窄——`disjoint` 可相加、`subset_of` 取并集
  包络、`overlap_known` 按 `|A∪B|=|A|+|B|-|A∩B|` 收窄；**跨来源重叠无法识别时绝不相加**，
  下界取 `max`、上界取各上界之和（理论包络），并集宽度整体计入结构性未知。
- **未知纪律**：隐私小样本抑制（`suppressed`）不记零，只产生点状未知；移动信号覆盖下降
  只扩大未知（开放上界）；未观测量永远不被写成确定数。
- **版本纪律**：隐私阈值、覆盖率或来源数据修订只生成新 `estimate_version`（输入快照记录
  采用的来源行集合指纹）；旧版本结果不原地改写，**旧预案保留当时分母**，晚到登记只进入新版本。
- **基线叠加**：区间结果保存净变化 `[delta_lower, delta_upper]`；关联覆盖任务后输出
  `可达需求 = 基线可达人口 + 净变化区间`（人数下界非负）。有界网格恒满足
  `上界-下界 = 抽样误差半宽 + 结构性未知`。

### 3.8 六类验收样例（窗口 2026-07-15 09:00–10:00 UTC）

| 验收情形 | 网格 | 预期区间结果 |
| --- | --- | --- |
| ① 节假日景区流入 | G1 | 移动 200×系数2.0=400±10%→[360,440]，与景区签到[350,1200]按已知重叠[300,400]收窄为 **[360,1340]**（无规则时上界会是 1640） |
| ② 寄宿学校放假 | G2 | 移动[72,88] 与留校点名[60,500] 为 subset_of → 并集 **[72,500]** |
| ③ 跨来源重复观测 | G3 | 景区[100,300] 与学校[40,100] 无重叠规则 → 下界取 max=**100（非 140，证明不相加）**，上界 400 |
| ④ 移动信号覆盖下降 | G8 | OP2 覆盖率 0.30 且不稳、未核验 → 采样 60 仅作下界，**上界 NULL 不可估** |
| ⑤ 隐私小样本抑制 | G6 | 移动信号与签到均被抑制（2 条点状未知，不记零），仅容量 200 约束上界 → **[0,200]** |
| ⑥ 转移登记晚到 | G8 | 首轮减量 80；晚到 50 人只进入新版本 → 减量 **80→130**，旧版本保留 80 的分母 |

## 4. 小型可手算样例（每条边 1000m / 60km/h = 1 分钟，T0=2026-07-15 08:00 UTC）

- `EV1`：E3 河东桥 08:05–08:20 临时封闭，N3 不可等待；

- `EV3`：E7 东站引道 C1 时“尚未恢复”，C2 修订为 08:40 重开；

  G5 比例和 1.2、G6 人口修订 1000→1200、G7 属另一边界、G8 仅靠 E7 外接（恢复验证）。

## 5. 已执行的验证与结论

以下验证均在本工作区实际执行通过：

1. **后端单元/集成测试 52 项全部通过**（`pytest`，约 31 秒）：
   - 单向边、绕行、整段封路判断（进入时开放但行驶中撞上也判不可行）、分时限速整段生效；
   - 不可等待节点无法等待、等待后超时剪枝、安置点按实际到达时刻开放、见证路径留痕；
   - 多出口互斥份额、多点重叠只计一次、四类未知边界、证据截止标注、边界过滤；
   - 同签名任务复用与引用计数、不同出发时刻绝不共享缓存、查看者释放不取消共享任务；
   - 临时事件即时失效、重开恢复此前不可达网格、旧任务不能覆盖新版本索引、失效窗口重建、
     **旧截止点快照在后续修订录入后仍可精确复现（追加式事件修订回归测试）**；
   - 共同分母对比三因分解、人口修订不计入道路效应、边界变化单列、发布清单完整性；

## 6. 主要 API 一览

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/scenarios` | 按签名创建/复用情景并同步得到覆盖面 |
| GET | `/tasks/{id}/summary` `/grids` `/arrivals` `/witness` | 汇总、份额、节点到达、网格下钻 |
| POST | `/tasks/{id}/release` | 查看者离开（引用计数，不取消他人任务） |
| POST | `/events` | 临时封路/限速登记并即时失效受影响范围 |
| POST | `/cache/precompute` `/cache/rebuild` `/cache/invalidate` | 预计算、重建、按边失效 |
| POST | `/comparisons` | 共同分母对比与三因分解 |
| POST | `/publications` GET `/publications` | 结果发布与完整输入清单（可关联临时暴露估计版本） |
| GET | `/sources/*` | 来源原文、事件审计、边修订、安置点、人口连接 |
| POST | `/exposure/estimates` GET `/exposure/estimates` | 生成/列出临时暴露人口估计版本（修订只增版本） |
| GET | `/exposure/estimates/{id}` `/exposure/estimates/{id}/grid/{grid}` | 版本详情与单网格逐来源证据下钻 |
| POST | `/exposure/mobile-signals` | 移动信号采样登记（覆盖下降/隐私抑制/核验状态） |
| POST | `/exposure/venue-presence` | 景区/寄宿学校在场登记（含隐私抑制） |
| POST | `/exposure/transfers` | 临时转移登记（`late_arrival` 标记晚到） |
| POST | `/exposure/overlap-rules` | 登记可证明的跨来源重叠关系 |
| GET | `/exposure/sources` | 浏览全部临时来源、容量、校准系数与重叠规则 |
| POST | `/admin/reseed` `/admin/apply-c2-revision` | 样例数据管理 |
